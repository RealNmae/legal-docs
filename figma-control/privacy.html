Figma Control Privacy Policy

Effective date: June 3, 2026

Summary

Figma Control does not collect, sell, rent, share, or transmit personal data to the developer or third parties.

Local Data

The app stores configuration locally on the user's Mac. This configuration can include controller mappings, plugin command names, hotkey assignments, LED colors, Bluetooth device names, USB serial port patterns, and local WebSocket settings.

The app also keeps a short in-memory event log for diagnostics. A diagnostic file is created only when the user explicitly chooses Export Logs.

Bluetooth

The app uses Bluetooth to scan for and connect to the user's custom encoder and keypad controllers. Bluetooth data is used only for local controller communication.

USB Serial

The app can read a local USB serial port when the user enables legacy wired-controller support. USB serial data is used only for local controller communication and is not sent to the developer or third parties.

Local Network

The app runs a local WebSocket server on the Mac so the Figma plugin can receive user-configured controller commands. This local server is intended for same-device workflow communication.

Automation And Accessibility

When enabled by the user, the app uses macOS Automation and Accessibility permissions to activate Figma, open the configured plugin menu item, send user-configured hotkeys, and read modifier key state for Shift/Cmd layer behavior.

The app does not record typed text.

Third-Party Services

The app does not include advertising, analytics SDKs, tracking SDKs, or third-party data collection services.
