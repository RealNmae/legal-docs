Figma Control Support

Figma Control is a macOS utility for configuring custom Bluetooth encoder/keypad controllers and an optional legacy USB serial controller for Figma workflows.

Getting Started

  1. Open Figma Control from the menu bar.
  2. Connect the encoder and keypad controllers over Bluetooth, or enable Legacy USB in Settings for the older wired controller.
  3. Click a control in the visual device layout.
  4. Assign a Figma plugin command, hotkey, layer action, joystick action, or LED preset.
  5. Save the configuration.

Permissions

  • Bluetooth: connects to the user's custom BLE controllers.
  • USB Serial: reads the optional legacy wired controller when enabled by the user.
  • Accessibility: sends user-configured hotkeys and reads modifier key state for Shift/Cmd layers.
  • Automation: activates Figma and opens the configured Figma plugin workflow.

Devices Do Not Connect

  • Confirm the controllers are powered on.
  • Use the reconnect button in Figma Control.
  • Check that Bluetooth permission is enabled in System Settings.
  • For the legacy wired controller, open Settings, enable Legacy USB, confirm baud is 115200, and check that the port pattern matches the Mac port such as /dev/cu.usbmodem*.
  • Restart the controller and reopen the app if macOS keeps the old BLE session.

Figma Commands Do Not Run

  • Open Figma and keep it installed as the desktop app.
  • Confirm Automation permission is enabled for Figma Control.
  • Confirm Accessibility permission is enabled if the mapping uses hotkeys.
  • Check that the configured plugin menu path matches the plugin installed in Figma.

Diagnostics

Use Export Logs in the app to create a local diagnostic text file. Diagnostics are saved only when the user explicitly exports them.
